## 1. Project Overview

Herbs Connect is a hypothetical small herbal wellness business created for
the Web Development (Introduction) module.

The idea behind the organisation is based on traditional herbal practices
and the interest in natural wellness products. The website is designed to
give visitors a simple way to learn about Herbs Connect, view its products,
make an enquiry and find contact information.

The website focuses on traditional herbal wellness rather than making
medical claims about the products. It aims to present the organisation and
its products in a clear and responsible way.

The website was developed as part of Part 1 of the Web Development
Portfolio of Evidence (PoE). The initial version focuses on the HTML
structure, content, navigation, file organisation and sourcing of website
assets.

---

## 2. Website Goals and Objectives

The main goal of the Herbs Connect website is to create a simple and
informative online presence for the business.

The objectives are to:

- Introduce visitors to Herbs Connect.
- Explain the organisation's background, mission and vision.
- Display the herbal products offered by the business.
- Allow visitors to make product enquiries.
- Provide clear contact information.
- Make the website easy to navigate.
- Create a foundation that can be improved with CSS and JavaScript in
  later parts of the project.

### Key Performance Indicators (KPIs)

The proposed KPIs for the website include:

- Number of visitors to the website.
- Number of product page visits.
- Number of enquiries submitted.
- Number of visitors who use the contact page.
- Successful navigation between the main website pages.

---

## 3. Target Audience

The target audience consists mainly of adults who are interested in
traditional herbal practices, natural wellness products and learning more
about herbs used in traditional cultures.

The website is also intended for people who may be unfamiliar with herbal
products and want to learn more before making an enquiry.

---

## 4. Key Features and Functionality

The website contains five main pages:

### Home

The homepage introduces Herbs Connect and provides links to the main
sections of the website.

### About Us

The About Us page explains the organisation's story, mission, vision,
values and target audience.

### Products

The Products page presents the herbal products available from Herbs
Connect.

### Enquiry

The Enquiry page contains an HTML form that allows visitors to provide
their details and ask questions about products.

### Contact

The Contact page provides information about how visitors can contact the
organisation and includes information about its proposed locations.
